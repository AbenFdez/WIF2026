**Ponentes:** Lorena Méndez Otero y Alejandra Ben Fernández

## Cómo ver la versión HTML

`WIF2026_Capa_Ontologica_en_Fabric.html` es una presentación en un único archivo HTML, con las imágenes incluidas. GitHub no muestra los HTML directamente, así que:

1. Pulsa el archivo y luego **Download raw file** (icono de descarga).
2. Ábrelo con cualquier navegador.

**Atajos:** `→` / `Espacio` siguiente · `←` anterior · `G` vista general · `F` pantalla completa · `L` láser · `Esc` cerrar.

## Contenido

1. **Parte teórica · Del dato al conocimiento**: por qué hablar ahora de ontologías, qué es una ontología, claves para diseñarla, qué es Fabric IQ, ontología vs. modelo semántico, y evolución de la capa gold a la capa ontológica.
2. **Parte teórica · Ontologías en Microsoft Fabric**: dónde vive la ontología, arquitectura, elementos principales, consumo, requisitos y limitaciones actuales, y cómo crearla paso a paso (entidades, propiedades, metadatos, relaciones y grafo).
3. **Parte práctica · Demo**: análisis de parques eólicos en Galicia: fuentes de datos, grafo del dominio eólico, modelo semántico y data binding.
