# Demo

Modelo semántico e informe en formato **Power BI Project (.pbip)** con **TMDL**. Así las tablas, relaciones y medidas se pueden leer y versionar en GitHub.

Para guardarlo así: en Power BI Desktop, **Archivo → Guardar como → Proyecto de Power BI (.pbip)**. El formato TMDL se activa en Opciones → Características en versión preliminar.
